# 기기 참여 승인 한 줄 데모

## 실행 방법

1. macOS Apple Silicon(M1/M2/M3/M4)에서 저장소를 엽니다.
2. 터미널에서 저장소의 `app` 폴더로 이동합니다.
3. 아래 한 줄을 실행합니다.

   ```sh
   node scripts/demo-office-pairing.mjs
   ```

완료까지 잠시 기다리면 됩니다. 관리자나 팀 계정을 미리 준비할 필요가 없습니다. 매번 임의의 테스트 계정과 별도 임시 데이터베이스를 만들며, 개발용 데이터베이스에는 연결하지 않습니다.

실행에 필요한 `darwin-arm64` office 런타임 번들이 없거나 현재 컴퓨터에 맞지 않으면, 스크립트가 준비 상태를 확인하라는 안내를 출력하고 종료합니다. 이 데모는 번들을 직접 준비하지 않습니다. 준비가 끝난 뒤 같은 명령을 다시 실행하세요.

실행 중 `Ctrl-C`를 누르면 서버와 데이터베이스를 종료하고 임시 파일을 지웁니다. 정상 종료 때도 같은 정리를 수행합니다.

## 화면 읽는 법

각 결과 줄은 다음처럼 표시됩니다.

```text
PASS  승인 전 디렉터리 접근 차단 — HTTP 403
```

- `PASS`는 기대한 동작을 확인했다는 뜻입니다.
- `FAIL`은 기대와 다른 응답이 돌아왔거나 화면에서 구분 정보를 찾지 못했다는 뜻입니다. 하나라도 있으면 명령이 실패 코드로 끝납니다.
- `HTTP 403`은 이 요청이 허용되지 않았다는 서버 응답입니다. 이 시나리오에서는 승인 전 디렉터리 열기를 차단한 결과라서 `PASS`입니다.
- 같은 별명인 기기 A와 B는 관리자 대기열에서 `민수 · 코드` 형태로 구분합니다. 코드는 기기의 공개키 지문 일부이며, 개인키나 비밀번호가 아닙니다.
- 마지막 `결과: n/n PASS`에서 모든 항목이 통과했는지 확인합니다.

데모는 초대 발급, 두 기기의 참여 요청, 승인 전 접근 거절, 같은 별명 구분, 관리자 승인, 거절된 요청과 취소된 초대 재사용 방지, 위조 서명·증명 재사용·만료 거절을 차례로 보여 줍니다. 계정 비밀번호와 기기 개인키는 화면에 출력하지 않습니다.
