## 판단 필요 (고치지 않음)
1. **스크린샷이 낡았다.** 위 줄바꿈·제목 수정 뒤 화면과 PNG의 줄 나눔이 조금 다르다. 랩에서 다시 찍어 교체해야 한다. 확인 단계(위험 버튼)와 "지웠어요" 상태는 어느 PNG에도 없다.
2. **말투가 섞였다.** 패널 1은 PRD 원문 그대로 합니다체("찾아 줍니다", "않습니다"), 나머지는 해요체다. 앱 전체 톤 결정이 필요하다.
3. **한 문장 원칙.** 사양 부족(패널 3)은 이유와 해결이 두 문장 + 보조 문장이고, 지우기 확인 설명은 한 문장에 절이 셋이다. "저장 공간이 부족해 켤 수 없어요. 200MB 이상 비우면 다시 켤 수 있어요." 식으로 줄일지 결정이 필요하다. 보조 문장 "단어 검색은 그대로…"는 버튼 문구와 겹친다.
4. **메모리 부족 사유.** F8.3a는 메모리·디스크 둘 다 말하는데 시안은 디스크만 보여 준다(보고서에 가정으로 적힘). 사유별 문구 한 줄을 더 둘지 정해야 한다.
5. **위험 버튼 대비.** `[지우기]`는 `--danger` 배경에 `--text-on-accent`를 쓴다. 커스텀 accent에서 `--text-on-accent`는 accent 기준으로 계산되므로 빨강 위 대비가 보장되지 않는다. 앱 구현 때 danger 전용 글자색 토큰을 쓸지 정해야 한다.
6. **중복 스타일.** `.ss-btn`은 기존 `.lab-pill`과 거의 같다. 키트에는 일반 버튼이 없어(`FuseButton`은 되돌리기형) 새로 만들었다. 앱 구현 시 공용 버튼으로 통일. `[지우기]`를 `FuseButton`의 "되돌리기" 방식으로 할지도 선택 사항이다.
7. **지운 뒤 포커스.** 지우기 확정 후 [지우기…]가 비활성이 되어 포커스를 둘 곳이 없다. `role=status` 안내로 알리지만, 실제 앱에서는 포커스 목적지를 정해야 한다.
8. **용량 200MB는 임시값**(B0-a 측정 전). 보고서에 이미 명시됨.
